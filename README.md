# ZenFit: ваш путь к здоровью

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Android Studio](https://img.shields.io/badge/Android_Studio-3DDC84?style=for-the-badge&logo=androidstudio&logoColor=white)

О проекте
ZenFit — простое и удобное приложение. Оно предназначено для спортсменов и всех, кто следит за фигурой. Внутри вас ждут разнообразные рецепты, планы тренировок, калькулятор КБЖУ и многое другое. Начните свой путь к здоровому образу жизни уже сегодня!

Кому подходит
Новичкам — лёгкий старт в мире фитнеса и здорового питания.
Всем, кто следит за здоровьем — поддерживайте форму и питайтесь правильно с ZenFit.
ZenFit создан для всех. Особенно для тех, кто интересуется спортом и здоровым питанием.

Основные функции
Рецепты — здоровые и вкусные блюда.
Тренировки — проработанные программы тренировок с анимацией.
Калькулятор КБЖУ — точный учёт калорий и нутриентов.
Установка цели — отслеживание прогресса (например, шагов) и напоминания о достижении целей.
Наслаждайтесь широким выбором рецептов, тренировок и удобным калькулятором КБЖУ. ZenFit поможет вам достичь ваших целей и напомнит, когда вы их достигнете.

Технологии разработки
Android Studio — интегрированная среда разработки для Android.
Java — основной язык программирования.
Мы использовали передовые технологии для создания быстрого и надёжного приложения.

Важное ограничение
Приложение предназначено только для телефонов. Пожалуйста, не пытайтесь установить его на планшет или эмулятор..
